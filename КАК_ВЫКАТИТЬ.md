# Как выкатить Premium и возвраты — по шагам

Три шага. Всё делается один раз, минут за десять.

---

## Шаг 1. Взять токен Supabase

Токен — это длинный пароль, которым скрипт представляется Supabase вместо тебя.
Показывается он ровно один раз, поэтому копировать надо сразу.

1. Открой страницу: **https://supabase.com/dashboard/account/tokens**
   (я её уже открыл во вкладке браузера)
2. Убедись, что вошёл в тот же аккаунт, где лежит проект Antigram.
3. Справа над таблицей — зелёная кнопка **«Generate new token»**. Нажми её.
4. Появится поле для имени. Напиши что угодно, например `antigram-deploy`.
   Имя ни на что не влияет, нужно только чтобы ты потом узнал этот токен в списке.
5. Нажми кнопку подтверждения (**«Generate token»**).
6. Появится длинная строка, начинается с **`sbp_`**. Нажми на значок копирования
   рядом с ней.

**Важно:** после закрытия окна строку больше не покажут. Если потерял — просто
создай новый токен, старый можно удалить.

---

## Шаг 2. Запустить выкатку бэкенда

1. Открой Терминал: нажми **Cmd + Пробел**, набери `Терминал`, нажми Enter.
2. Скопируй эту строку, вставь в Терминал, нажми Enter:

```
cd ~/Desktop/Projects/ANTIGRAM/telegram-webapp
```

3. Теперь эту, тоже Enter:

```
./deploy_stars.sh
```

4. Скрипт напишет:
   `🔑  Вставь Supabase Personal Access Token`

   Вставь токен (**Cmd + V**) и нажми Enter.

   **На экране ничего не появится** — ни точек, ни звёздочек. Так и должно быть,
   пароли в Терминале не показываются. Просто вставь и жми Enter.

5. Дальше скрипт работает сам минуты две-три. Он применит изменения в базе,
   загрузит серверные функции и настроит связь с Telegram.

6. Готово, когда увидишь рамку со словами **«Готово! Всё задеплоено.»**

**Если что-то пошло не так:** скопируй последние строки из Терминала и пришли мне,
разберёмся. Ничего страшного не случится — скрипт можно запускать повторно.

---

## Шаг 3. Выкатить приложение

Фронтенд у вас собирается сам, как только изменения попадают в GitHub.
В том же Терминале, по одной строке:

```
git add -A
```

```
git commit -m "Premium: покупка, возвраты, /paysupport"
```

```
git push
```

Если при `git push` спросят логин и пароль — это GitHub. Обычный пароль от аккаунта
он не примет, нужен токен GitHub. Скажи мне, если до этого дойдёт.

После пуша Vercel сам соберёт и выложит приложение, это ещё пара минут.
Посмотреть, что сборка прошла, можно на **vercel.com** в проекте `antigram-webapp`.

---

## Шаг 4. Проверить, что всё живое

1. Напиши боту **`/paysupport`** — должен ответить текстом про оплаты и возвраты.
2. Открой приложение → **Premium** → кнопка **«Купить за 149 Stars»** → оплати.
   Ожидаемо: бот пишет «Premium активен до …», на странице появляется
   «Premium активен», дневной лимит кадров становится 8.
3. Открой любой кадр и поддержи его звёздами — должно работать как раньше.
4. Зайди в модерацию → **«★ Платежи и возвраты»** → увидишь оба платежа.
   Напротив каждого кнопка **«Вернуть звёзды»**: первый тап спрашивает
   подтверждение, второй возвращает.

---

## Если надо вернуть кому-то деньги

Никаких команд. Приложение → модерация → **«★ Платежи и возвраты»** → найти платёж
→ **«Вернуть звёзды»** → подтвердить.

Звёзды сначала уходят обратно человеку через Telegram, и только потом снимается
доступ. Если случайно нажал дважды — ничего не сломается, повторно деньги не уйдут.

---

## Порядок важен

Сначала шаг 2 (бэкенд), потом шаг 3 (приложение). Если сделать наоборот, кнопка
«Купить» появится у людей раньше, чем сервер научится принимать оплату.
